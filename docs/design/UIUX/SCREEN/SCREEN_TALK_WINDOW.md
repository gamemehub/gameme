# SCREEN_TALK_WINDOW v0.1

> 役割：**M03 Talk Window モード（通常会話）の画面仕様**。
> 最優先仕様＝添付画像「案B 顔アイコン式」。立ち絵は使わない（立ち絵・重要イベントは M04 VN Overlay）。
> 種別：設計ドキュメント（挙動の最終確定は実装・実機確認による）。

---

## 1. 概要

探索中の**通常会話**を担当する。NPC会話・調査・独り言・システム通知・選択肢。
Map を消さず、下部の会話枠＋左の顔アイコンで会話する。OFF / Undertale / Mother のテンポを目指し、**世界との地続き感を最優先**する。

基本フロー：

```
Map(M02) → 近づく → 調べる/話す → M03 Talk Window → (フラグ更新) → Map（同じ位置・向き）
```

---

## 2. 画面構成

- 下部会話枠（画面下部に固定。上 6〜7 割は探索 Map を見せる）
- 左に**顔アイコン**（PortraitSmall）
- 名前
- 本文
- 送り三角（▼）
- 任意：AUTO / SKIP / LOG（通常会話では控えめ、または非表示）

```
┌────────────────────────────────┐
│            （探索 Map / 立ち絵なし）            │
│                                                │
│ ┌────┐ ミオ                                   │
│ │顔 │ ……ここ、静かだね。                  ▼ │
│ │Icon│ 時計の音だけが、聞こえる……            │
│ └────┘                                        │
└────────────────────────────────┘
```

## 4. サブモード

| サブモード | 用途 | 顔アイコン | 名前 |
|---|---|---|---|
| **M03A** 通常会話【標準】 | NPC会話・調査 | あり（PortraitSmall） | あり |

---

## 5. 原則

- 探索 Map を**消さない**。画面を大きく塞がない。
- **立ち絵は使わない**（重要イベントの立ち絵は M04）。
- 常時ボタンを基本禁止（UI は会話中だけ現れる）。
- テンポ優先。短い会話が心地よいこと。

---

## 6. フロー / 状態保持

- 開始時：探索を pause（移動・近接判定を止め、**背景 Map とスプライトは残す**）。
- 会話中：本文を 1 件ずつ送る（タップ / 決定キー）。
- 終了時：探索を resume（**プレイヤーの位置・向きを保持**して復帰）。
- 重要イベントへ繋ぐ場合のみ、終了後に M04 VN Overlay を呼ぶ（通常会話単体では Map へ戻る）。

---

## 7. 顔アイコン素材（PortraitSmall）

- 正方形トリミング・小サイズ・表情差分。
- 詳細仕様（サイズ・命名規則・表情キー）は ASSET_SPEC / Character Bible を参照。
- 命名は表情キーで識別可能にする（例：`mio_icon_normal` / `mio_icon_anxious` …）。

---

## 8. 壊れない設計

- 顔アイコンが無い場合は**アイコンを非表示にしてテキストだけで進行**（会話は止めない）。
- 名前が無い場合（独り言・通知）は名前行を出さない。

---

## 9. 既存実装との対応

- 既存 **M03A エンジン**（下部 DialogBox + `WK.pause/resume`、dev で時計塔検証済み）を踏襲する。
- 本仕様で追加するのは**顔アイコン（PortraitSmall）の接続**のみ。会話送り・背景保持・位置復帰の仕組みは既存を流用。

---

## 10. 禁止事項

- 常時表示ボタン。
- 立ち絵・バストアップの表示（→ M04）。
- 全画面化・探索背景を消すこと。

---

## 11. M04 との境界

- 通常会話・調査・独り言・通知・選択肢 → **M03 Talk Window（本書）**。
- 記憶断片・白層化・章ラスト・ボス前後・感情が大きく動く重要会話・立ち絵会話 → **M04 VN Overlay**。
