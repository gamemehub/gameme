# UI/Map ベンチマーク設計方針（2026-07）

状態: v0.1 / 設計方針（受賞級8作品ベンチマーク × 既存正本統合）
作成: 2026-07-02
対象正本: `docs/design/UIUX/` 配下（BIBLE / UIUX_MASTER / MODE_DEFINITION / SCREEN_TALK_WINDOW / SCREEN_VN_OVERLAY / DESIGN_TOKEN / COMPONENT_DEFINITIONS）
前提: 「今までのUI/Mapがダメだった」を、ベンチマークと設計に基づいて作り直すための方針。既存の4段階トーク表示（Drive: talk_window_comparison）と8エリア構成（Drive: MAP_MASTER_CH01）を正とし、それを強化する形でまとめる。

---

## 0. 核心原則
**「今この情報が無いとプレイヤーが詰むか？」— 詰まないUIは全部隠す。**
テーマ「見たいのに、見ない方が守れる」を *全部見せないUI* に翻訳する。抑制は妥協ではなくテーマそのもの。これで失敗①(ボタン過多)・②(Map崩れ)・③(世界観と不一致)を同時に解消する。

---

## 1. ベンチマーク参照作品（実在・受賞級／何を盗むか）
- **Kentucky Route Zero**：固有名詞・記憶語に滲みシェーダ＝状態を「読む体験」に。選択肢は重く見せない。
- **Night in the Woods**：近接半径に入った時だけUI表示（近接層の直接の手本）／再訪で物語が継続する報酬構造。
- **The House in Fata Morgana**：表情差分を増やすより、光・彩度・陰影で感情を運ぶ。バストアップで「見せる」瞬間を作る。
- **Life is Strange**：逆再生ブラー＋控えめ円環＋SEで「ログ/アンログ逆流」。ゲージ・数値を出さず「後から効く」。
- **Disco Elysium**：内なる声＝色分け。intent(observe/avoid/ask/wait)を色・質感で（語は出さない）。ログは縦カラム積み。
- **Doki Doki Literature Club**：UIの破壊＝物語（名前抜け/グリッチ/ログ逆流）を「1章1回級の事件」として予算管理。
- **SIMULACRA / Sara is Missing**：スマホ/ログUIは現実を完コピしない（現実模倣度に上限）。
- **Undertale / MOTHER / OFF**：短文テンポの心地よさ（Lv1の手本）。

出典URL一覧は末尾。

## 2. 二層可視性モデル（"常時ボタン過多"の解消）
| 層 | 出るタイミング | 中身 |
|---|---|---|
| 恒常層 | 常時 | **現在地エリア名・17:17時計のみ**（これ以外は常時表示しない） |
| エリア遷移層 | エリア境界に近接／通過時 | 接続点(threshold)マーカー＋通過後のエリア名タイトルカード（M11遷移0.6s） |
| 近接層 | トウが近接半径に入った時だけ | 行動文（「本棚を調べる」「見ないでおく」）※抽象語禁止 |
| マーカー層 | 対象が画面内かつ未消化 | 会話「…」／調べ「✦」／記憶断片(MF)専用／セーブ点／パズル(PZ)。アイコンのみ |
| 演出層 | 物語イベント時のみ | 白層・名前抜け・ログ逆流・剥がしSE（Lv3/Lv4と連動・頻度予算で管理） |

判断は一問：**「今この情報が無いと詰むか？」** 詰まないものは近接層・演出層・M12へ落とす。

## 3. トークウィンドウ4段階表示レベル（既存M03/M04へ統合）
既存 talk_window_comparison の Lv1-4 を、正本の M03/M04 粒度として再配置する。**全Lv共通の不変条件＝Map背景を消さない／常時ボタンなし／抽象語を出さず行動文。**

| Lv | = 既存モード | 発火条件 | レイアウト | モーション | 参照（盗む点） |
|---|---|---|---|---|---|
| **Lv1 顔アイコン** | M03A（PortraitSmall） | 通常会話・調査・独り言(M03C)・通知(M03D) | 下部会話枠＋左64–96px顔。上6-7割Map | 入り0.15-0.2s/抜け0.3s、送り即時＋120ms | Undertale/MOTHER/OFF＝短文テンポ、NITW＝近接感 |
| **Lv2 表情差分** | M03A（表情差分運用） | ミオの揺れ・違和感・小イベント（M03のまま） | Lv1と同一枠。表情差分＋ごく弱い環境変化（縁が沈む/名前色くすむ） | 表情クロスフェード0.25s、送りディレイ160-200ms | KRZ＝記憶語に弱い滲み、Fata Morgana＝光・彩度で感情 |
| **Lv3 バストアップ** | M04 VN Overlay | 記憶断片(MF)・白層化・中ボス(⑦)前後 | 暗幕でMap沈めて残す＋バストアップ＋会話枠 | 暗幕入り0.4s/抜け0.6s、立ち絵にわずかな上方向パララックス | Fata Morgana＝重い塗り、Life is Strange＝逆再生ブラー、Disco＝色分け |
| **Lv4 全身立ち絵** | M04 特別演出 | 章ラスト・章ボス(⑧)・True End | 全身立ち絵、Map最も深く沈める（消さない）、会話枠最小/一時消し | 立上げ0.6-0.8s、抜け更に長く。名前抜け/ログ逆流/剥がしSEはここに集約 | Fata Morgana＝一枚絵級ピーク、DDLC＝UI破壊 |

**鉄則**：通常はLv1に張り付く。Lv2は「違和感」発火時のみ。Lv3/Lv4は頻度予算で上限管理。**Lvを上げる＝感情の落差を使うこと**。常用したら効果が死ぬ。

## 4. 8エリア探索MAP（MAP_MASTER_CH01）のUI
エリア制探索アドベンチャー（①記録室→②教室→③時計広場→④図書館→⑤時計塔前→⑥地下回廊→⑦記憶保管庫[中ボス]→⑧記録保存官の間[章ボス]）としてUIを設計。

### 4.1 エリア接続・遷移・現在地
- **接続点(threshold)は各エリアの固定端（扉/階段/左右端）にアンカー**。近接で「地下回廊へ降りる」等の行動文（常時矢印は出さない）。
- エリア移動は**必ずM11遷移経由**（入力ロックで二重遷移防止＝Map崩れ・状態不整合の根本対策）。遷移後にエリア名タイトルカードを短く（KRZ/Fata Morganaの静けさ）。
- **ミニマップは常時表示しない**。8エリア接続図は**M12記録の新タブ「区域図」**として一時停止時のみ参照。

### 4.2 記憶断片(MF01-07)・セーブ(S1-8)・パズル(PZ01-03)
- **記憶断片(MF)**：調べ物「✦」と別マーカー（弱く明滅する白点＝白層系）。近接でLv3/M04（`showMemory`）へ。収集済みはマーカーを消し、再訪時は痕跡だけ残す。
- **セーブ点(S1-8)**：セーブアイコンを常時置かず、**ダイエジェティックな世界内オブジェクト**（記録端末/掲示板）に近接してM09を開く（Simulacra教訓：現実模倣しすぎない）。
- **パズル(PZ01-03)**：近接層にのみ操作UIを出し、解決後はマーカーを`consumed`にして操作UIを完全撤収。

### 4.3 再訪時のUI動的変化（エンジン実像に接続）
- マーカーは4状態のステートマシン：`unvisited / available / consumed / locked`。
- **実装は既存機構で足りる**：`walk`オブジェクトは`sceneIfFlag:{flag,scene}`で分岐可能、`CH01_STATE.flags`で通過記録。**再訪時のUI差し替えは walk の flag 分岐で表現**。※`vn`/`phone`/`memory`はフラグ分岐を持たない（CH01仕様§0-3）ため、**動的変化ロジックは walk 層に集約**する。新規シーン増設ではなくフラグ分岐で再訪差分を作る（参照切れ回避）。

### 4.4 Map崩れの防止（エリア制版）
- **エリア単位スキャフォールド**：各エリアを独立スキャフォールドとし、恒常層はエリア共通のアンカーグリッド（時計=右上固定、現在地=その下）で全8エリア統一。エリアごとに作り込まない＝崩れの温床を断つ。
- **ワールド座標UI（…/✦/MF/threshold/白層）とスクリーン座標UI（時計/現在地/会話枠/選択肢）を分離**（混在がレイアウト崩壊の主因）。
- マーカーは画面端で内側クランプ、重なりは優先度（会話…＞調べ✦＞MF）と最小間隔で解決。
- 遷移は必ずM11経由＋`isTransitioning`ガードで二重入力の崩れを封じる。

## 6. 正本への反映指示
| 正本ファイル | 追加/改訂 |
|---|---|
| `SCREEN_TALK_WINDOW` | 表示レベルLv1–Lv4対応表（発火/モーション/参照）。Lv2運用（表情差分＋記憶語の滲み＋送りディレイ延長）。全Lv不変条件「Map背景を消さない」 |
| `SCREEN_VN_OVERLAY` | Lv3(中ボス級)/Lv4(章ラスト/章ボス/TrueEnd)の切り分け、暗幕イージング。名前抜け/ログ逆流/剥がしSEはLv4集約 |
| `MODE_DEFINITION`(M02) | エリア制探索UI：遷移層/接続点threshold/エリア名タイトルカード/ミニマップ非常時表示/マーカー4状態 |
| `MODE_DEFINITION`(M12) | 記録に「区域図」タブ（8エリア接続を一時停止時のみ参照） |
| `MODE_DEFINITION`(M09) | セーブ点をダイエジェティックな世界内オブジェクト近接で開く方式 |
| `COMPONENT_DEFINITIONS` | 記憶断片(MF)マーカー・接続点threshold・マーカー状態機械・エリアスキャフォールド。再訪UI変化は`walk`+`sceneIfFlag`前提 |
| `DESIGN_TOKEN` | セーフエリア/アンカートークン、Lv別モーショントークン、感情トークン(ink/veil/absence/signal) |
| `UIUX_MASTER`/`BIBLE` | 表示レベル頻度予算表（Lv2=違和感時のみ/Lv3=中ボス級/Lv4=章あたり数回上限）、巻頭原則「抑制＝テーマ」 |
