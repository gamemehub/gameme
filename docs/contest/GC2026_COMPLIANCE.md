## 🔴 絶対に守る（違反＝失格・審査対象外）

### C-1. 特定作品・作家のスタイル模倣を禁止（AIガイドライン2）
> 「特定の作家や作品独自の個性及びスタイルが認識できると主催者が判断する場合には、
> 法的利益の侵害のおそれがあるとして**審査の対象外**」

- **画像生成プロンプトに固有名詞を入れない**：`EarthBound` / `MOTHER` / `Mother 3` / `糸井` /
  実在作家名・作品名・キャラ名を禁止。
- 代わりに**質感の一般語**で組む：`warm 16-bit pixel art, muted dusk palette,
  rounded friendly shapes, oblique projection, hand-drawn feel` 等。
- 「特定個人の声・絵柄」も対象。実在人物を想起させる素材を作らない。
- 独自スタイルの固定は自前LoRA（Scenario等）で行い、**特定作品と識別されない絵柄**にする。
- ✅ 設計ドキュメント内で開発方針として「MOTHER風」と説明するのは可。
  ✗ ただし**成果物の絵・音・文が特定作品と識別されてはならない**。

### C-2. 第三者の権利を侵害しない（規約8条・AIガイドライン4）
- アセット・コード・音楽・フォントは、**ライセンス上ゲームで使用・改変・商用化可能**なもののみ。
- 使用した生成AIの利用規約を遵守し、**商用利用可のモデル/プランを使う**
  （モデル・バージョンで可否が変わる。要確認）。
- フリー素材はライセンス（CC0等）を確認し `assets/CREDITS.md` に記録。

### C-3. オリジナル・未発売・未受賞（規約2条3項/8条）
- 完全オリジナルであること。他コンテスト未受賞、営利販売・配信なし。
- 無料公開（SNS・個人サイト・無料公開サイト）は「未発売」扱いで応募可。
  ただし現状は**パスワード保護のプロトタイプ**を維持（`FEED_game.html` はパスワード運用）。

## 🟡 運用で担保する（提出時に必要）

### C-4. AI使用ログを最初から残す（AIガイドライン3）
応募時に「①ツール名・モデル・バージョン ②使用工程と用途 ③使用時期」の申告が必要。
以下を継続更新する（後追いで作らない）：

- **`assets/PROMPTS.md`**：画像/音の生成ツール・モデル・バージョン・プロンプト・シード・生成日
- **`docs/contest/AI_USAGE_LOG.md`**：工程別のAI利用一覧（コード生成含む。Claude Code / Cursor 等も対象）
- コミットメッセージやPRに、AI利用が追える情報を残す。

### C-5. ゲーム内リアルタイムAIの制約（AIガイドライン2）
本作は現状オフラインの決め打ちシナリオ＝**該当しない（有利）**。
将来AIで動的生成を入れる場合のみ、以下を満たすこと：
- ユーザー入力を機能提供以外に使わない／保持・追加学習しない。
- 審査側に費用（API料金等）を発生させない（応募者負担にする）。

### C-6. 審査で評価される軸に合わせる（規約3条2項）
> 新規性・独創性・**娯楽性・完成度**・商品化可能性を総合評価。

- 読み物ではなく**遊べて面白い**状態を優先（開発指針の垂直スライス方針と一致）。
- 入賞時はソースコード・アセット・仕様書等**全データ提出義務**（4条6項）。
  → データ・権利をクリーンに保つこと自体が入賞条件。

## 入賞後に発生する事項（着手前でも認識しておく）

- 賞金支払完了時に、作品は**主催者と1/2ずつの共同著作物**になる（4条2・3項）。
- 著作者人格権の不行使に同意（4条4項）。
- 入賞後は公開中の作品の**停止・削除**を求められうる（4条8項）。
- 落選作品の著作権は応募者に残る（4条9項）。

## 開発フローに落とした具体アクション

1. `PRODUCTION_FLOW.md` のプロンプト例から固有名詞を除去済み（C-1）。
2. アセット生成のたびに `PROMPTS.md` と `AI_USAGE_LOG.md` を更新（C-4）。
3. 素材採用時にライセンスを `CREDITS.md` に記録（C-2）。
4. 公開はパスワード保護のプロトタイプに限定（C-3）。
5. エントリー開始後、**確定版の規約で本チェックリストを更新**する。
