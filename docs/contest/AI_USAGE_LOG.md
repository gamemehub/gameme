## 記録ルール
- 画像・音の生成は、プロンプト/シード/生成日を `assets/PROMPTS.md` に、本表に工程サマリを残す。
- コード生成AI（Claude Code / Cursor 等）も申告対象。工程を本表に記録する。
- モデル/バージョンで商用利用可否が変わるため、**商用利用可のモデル/プラン**を使い、確認結果を記録する。
- 素材のライセンス（フリー素材含む）は `assets/CREDITS.md` に別途記録する。
