## 2. 禁止事項（Canon Guard）

- **金魚 / 水槽 / 水槽音 / 「記録されない小さな命」**: 非採用・復活禁止。台詞・ト書き・Interactable に出さない。
- **時計塔**: Landmark のみ。**内部 Event・内部描写・分類・制度・鐘・組織・ノア恒常配置を一切出さない**（U-004）。見上げる Inspect も「内側のことは何も見えない」まで。
- **言ってはいけない（全シーン共通）**: 記憶局全貌 / アンログ思想 / 白層科学 / 未来のトウ / 母の保存詳細 / ミオ=鍵・原型 / 時計塔の内部・分類・鐘 / 金魚。
- **母の状態**: 断定しない（CH02+）。「不在」の感覚のみ。
- **ミオの人物評**: 「優しい子」等の直接説明禁止。行動・反応・間で立てる。
- **Lore Dump**: 設定説明3行以上連続する NPC 会話を置かない。同じ情報を NPC/本/掲示で重複説明しない。
- **S8〜S11**: 説明台詞の増量禁止。理解は Player Action / Visual で成立させる。

## 3. 3原則（横断 Gate）

1. **WORLD → SUSPICION → UI**（UI が先に答えを言わない。「白層化率」名称は S8 の操作失敗後に初判読）
2. **OBSERVATION ≠ CALLOUT**（観測=悪化系動詞と、呼びかけ=応答を待つ行為を混ぜない）
3. **CALLOUT SUCCESS ≠ CAPTURE CAUSE**（S11 の介入原因を断定しない。「呼びかけたから捕まった」と読ませる演出・台詞を作らない）

## 4. 確定 canon 事実（実装が依拠してよいもの）

- ミオは 17:17 に時計塔前へ寄る癖がある。「最初の日だけ思い出せない」。
- ベンチは4席＋5席目の「跡」。5席目はミオにだけ「空いている」。ロケは **C2 ベンチで確定**（教室/学校案は削除済み 2026-08-13。上位 canon に残る学校記述は STALE CANON CANDIDATE であり従わない）。
- 名を呼ぶ→本人が「はい」と応える＝canon 固有の攻略反転。
- S11: 呼びかけは**成功する**。ミオは一度本当に自分に戻る。直後に記憶局が介入し連れ去る（連れ去りの事実=canon 確定。見せ方=演出調整範囲）。記憶局の台詞は最小（「……保護のため、です。」）。
- 通知: 本文空白・既読のみ。終端で送信者がミオ→トウに反転。「次回観測予定：明日17:17」。
- S0=受動的喪失（忘れられる）↔ S11=構造的喪失（正しかったのに奪われた）の意味論的反転。
- Story 状態3種: `observer_is_tou` / `mio_carried_lost` / `notification_sender_inverted`。
