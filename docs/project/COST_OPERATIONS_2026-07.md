## 0. 最重要の結論（サブスク vs API の自動化適性）
**「AIが止まらない24h自律」を狙うなら、無人ループは "API従量" が正規ルート。Maxサブスクは対話/軽作業向き。**

| 観点 | Maxサブスク($100/$200) | API従量 |
|---|---|---|
| 24h無人ループ | ⚠️ **週次上限で頭打ち** | ✅ 想定用途（上限はレート制限のみ） |
| ヘッドレス/サーバ常駐 | ❌ OAuthトークン抽出常駐はToS違反 | ✅ 正規 |
| 第三者エージェント基盤 | ❌ 対象外(2026/4〜) | ✅ 可 |
| コスト予測性 | ◎ 定額 | △ 使用量比例（モデル選定が支配的） |

補足：自分のMac mini上で**公式Claude Code/Agent SDKをローカル実行する限りはMaxでも技術的に可能**だが、週次上限で無人フル稼働は途切れる。→ **自律ループはAPI、対話はMax** のハイブリッドが妥当。

## 1. 単価（取得日時点・要再確認）

**OpenAI（QA/レビュー用途）**：GPT-5.3-Codex = **$1.75/$14** ／ GPT-5.5 = **$5/$30**。ChatGPT Plus $20 / Pro $100。自動化はAPI直が無難。

**Mac mini(M2 Pro)電気代**：アイドル7W〜負荷185W。31円/kWh・24h常駐で **現実的（〜30W平均）＝月数百円/年5千円前後**、最大でも年5万円未満＝**総額に対し誤差**。

## 2. 24h自律ループの試算感（例示・要実測校正）
1日200モデルターン・各 入力80k(80%キャッシュ)＋出力8k と仮定：
- **Opus 4.8常用**：≈$62/日 ＝ **月 約$1,870（約28万円）**
- **Sonnet 5主力(導入価格)**：≈$25/日 ＝ **月 約$750（約11万円）**
→ **モデル選定がコストを支配**。Sonnet主力＋キャッシュ徹底＋Batch＋難所だけOpus で1/3以下に。トークン係数は自環境で `count_tokens` 実測して再校正すること。

## 4. 推奨：C（バランス）
理由：GPTの7月目標「AIが止まらない24h自律＋1エリア提出品質」に対し、**自律ループはAPI（ToS適合・週次上限なし）で継続稼働**させ、**対話・軽作業はMax定額で予測可能**に。コストは **Sonnet 5主力＋キャッシュ徹底＋Batch＋難所のみOpus 4.8** のモデル階層と、**Supervisorの日次コスト上限**で制御する（`tools/autonomy/` に実装済みの安全弁と直結）。GPT/Codexは QA/レビューに役割特化でAPI併用。電気代・保守は総額に対し軽微。

**段階導入**：まずSonnet主力＋日次上限 低め($10〜15/日) で回し、実トークンを `count_tokens` で実測 → 上限とモデル配分を再校正 → 必要に応じOpus比率を上げる。
