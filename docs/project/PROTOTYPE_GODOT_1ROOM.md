# Godot 1部屋プロトタイプ 仕様書（Phase1・Go/No-Go）

状態: v0.1 / 実装指示（PM→実装）
作成: 2026-07-02
目的: 「Godotで RewriteMemory の"探索するゲーム体験"が出せるか」を、**1部屋・3〜5日**で実測し **Go/No-Go** を判定する。合格ならGodotでCh1を1エリアずつ縦串化、不合格ならWeb+Phaserへ戻す。

## 絶対条件（GPT指定・厳守）
- **全面移行から始めない。** 8エリア・ボス・パズル・全UIを一気に作らない。
- **1部屋のみ／3〜5日／触って判定。** これを超えたら中断してレビューへ。
- ボス・パズル・セーブ・複数エリアの作り込みは**やらない**（エリア遷移は"1回・スタブ先"のみ）。

## 実装するもの（これだけ）
1. **歩行**：4方向（可能なら8方向）。`CharacterBody2D`。
2. **カメラ追従**：`Camera2D`（プレイヤー追従、部屋端でクランプ）。
3. **当たり判定**：広場の外周＋噴水/ベンチ等の障害物数個（`StaticBody2D`／簡易コリジョンで可）。
4. **近接インタラクション**：対象に近づくと行動プロンプト表示（NITW方式・`Area2D`）。決定キーで発火。抽象語禁止・行動文（「ミオに話しかける」「小包を調べる」「見ないでおく」）。
5. **NPC会話開始（ミオ）**：トークウィンドウ **UI Lv1（顔アイコン）→ Lv2（表情差分・不穏さ）**。Map背景は消さない。
6. **記憶断片1つ（小包）**：取得で **UI Lv3（バストアップ・背景を暗く沈めて残す）** の記憶シーンを1回。
7. **ログ逆流演出1回（5席目の跡）**：「見る/見ない」の選択→ 見た場合、17:17タイムスタンプ逆行＋名前が白く抜ける＋逆再生ブラー＋（SEは仮でよい）。**"1章1回級"の演出**として1回だけ。
8. **エリア遷移1回**：時計塔入口でフェード＋エリア名タイトルカード（0.6s）→ 空のスタブ部屋（中身は不要）。
9. **恒常UI**：右上に「現在地：白い広場 / 17:17」のみ。**それ以外は常時表示しない**（設計方針 `UIUX_BENCHMARK_2026-07.md` の二層可視性モデル準拠）。

## やらないこと
- ボス戦・記憶操作バトル
- パズル（本の並べ替え／時計合わせ／暗号解読）
- セーブ/ロード
- 8エリアの作り込み（遷移先はスタブ）
- 背景/タイルアートの作り込み・音楽（SEは仮）

## Go/No-Go 判定基準（実際に触って評価）
以下を**プレイして**評価する。定量ではなく体感で可。
1. **歩いていて気持ちいいか**（移動の応答・速度・カメラの追従感）
2. **世界を探索したくなるか**（近づく→調べる→分かる、の動機づけ）
3. **VN（会話・記憶・ログ逆流）への切り替えが自然か**（Map背景を保持したままの重ね）
4. **RewriteMemoryらしい空気が出ているか**（静けさ・不穏・"見ない方が守れる"のトーン）

- **合格（Go）**：そのままGodotでChapter01を1エリアずつ縦串化する。
- **不合格（No-Go）**：Web+Phaser（+Tauri）へ戻し、同じ1部屋仕様をPhaserで実装して再判定。
