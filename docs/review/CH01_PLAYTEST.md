## 0. 前提：解析した進行フロー

意図された本筋（推奨ルート）:

```
ch01_hook（白い広場／3日前）
  └→ ch01_morning_new（朝・台所・叔母）
       └→ ch01_walk_plaza【WALK】（小包 x35 / ミオ x55 / 5席目の跡 x90 / 時計塔 x140）
            ├ 小包を調べる → ch01_212_package_inspect → ch01_213_open_choice
            │     ├ 開ける（package_opened）→ ch01_213_package_contents →（walkに戻る）
            │     └ 開けない →（walkに戻る）
            └ ミオに話しかける（mio_first_talked）
                  ├ 通常 → ch01_211_mio_plaza_talk → ch01_clocktower
                  └ package_opened時 → ch01_214_mio_reacted（mio_reacted_to_package）→ ch01_clocktower
ch01_clocktower（夕方・ベンチ・「名前を呼ぶと音が止まる」）
  └→ ch01_explore_bench【EXPLORE ハブ】（話す / 5席目 / 時計塔 / 「17:17 →」skip）
       └ 17:17 → ch01_1717 → ch01_1717_after → ch01_bench_seats
            └→ ch01_060_choice（観察/逸らす/聞く/待つ）→ ch01_070a–d → ch01_070_reconstruction
                 └→ ch01_080_truth（真相＝関係が白く抜けている）
                      └→ ch01_anlog_flood【PHONE・アンログ共鳴ログ】→ ch01_anlog_end（送信者名 ミオ→トウ）
                           └→ ch01_099_continued（章末・「次の章へ」）
```

主要フラグ機構（既存）:
`package_opened` / `mio_reacted_to_package` … `ch01_070a–d` のボーナス台詞 `ifAllFlags` を解放。
`mio_first_talked` / `package_inspected` / `mio_reacted_observe|avoid|ask|wait` … セット済みだが**どこからも参照されない**（死にフラグ）。
`CH01_STATE.observation/trust/choseNotToLook` … 加算のみで Ch01 中の分岐には未使用。

## 1. 通しプレイ結果

| 区分 | 評価 | 要点 |
|---|---|---|
| 全体クリア可否 | ✅ クリア可能 | どのルートでも最終的に `ch01_099_continued` に到達。ハードな進行不能は無し |
| 所要時間（推定） | 約 8〜12 分 | テキスト主体・選択肢少なめ。読み速度依存 |
| 謎の提示（3分以内）| ✅ 達成 | 開幕30秒で「あなたは、誰ですか？」＋空白の17:17通知＋画面白化。掴みは非常に強い |
| ミオへの興味（10分以内）| △ 条件付き達成 | 核となる `ch01_clocktower`（呼名で安心する描写）は**スキップ可能**。本筋を通れば達成、外れると弱い |
| 続きを遊びたいか（終盤）| △ 良いが惜しい | 送信者名 ミオ→トウ の反転は不気味で良い。ただし最大級の引き「忘れないでね」が未発火（§7） |

**総評:** 「掴み（hook）」と「真相（080）」「アンログ共鳴ログ」は完成度が高い。一方で**中盤の導線が分岐順に強く依存**し、もっとも感情を動かすシーンが任意化・孤立化している。骨格は良く、配線（next の張り直し）で体験が大きく改善する段階。

## 2. 詰まりポイント

1. **【最重要・順序破壊】WALK で「5席目の跡」「時計塔」を先に調べると、夕方ハブへ直行してしまう。**
   - `ch01_walk_plaza` の `5席目の跡 → ch01_explore_seat`、`時計塔 → ch01_explore_tower` は、どちらも `next: ch01_explore_bench`（＝夕方の探索ハブ）。
   - つまり**ミオに話しかける前にオブジェクトを調べると、`ch01_clocktower`（夕方ベンチ導入＝呼名メカニクスの初出）とミオ広場会話を丸ごと飛ばして夜パートに入る。** 「なぜ急に夕方？なぜミオがベンチに？」と確実に混乱する。
   - さらにハブからは WALK へ戻れないため、**小包・ミオ広場会話・package 分岐が永久にロックされる**（後述の死にフラグ・未発火の主因）。

2. **EXPLORE ハブからの進め方が分かりにくい。** 先へ進む手段は右下の「17:17 →」スキップボタンのみ。色 `#3a4858`・9px と非常に地味で、ホットスポットを一巡した後「どうやって進む？」で手が止まる。明示的な「次へ進む」誘導が無い。

3. **再構成パズル（`ch01_070_reconstruction`）の選択に意味が無い。** 「正解」3つは `next: ch01_080_truth`、「17:17の空白メッセージ」は `next: null`。`null` 時は `ns()` が `si++` で結局 `ch01_080_truth` に進むため、**どれを選んでも同じ結末**。和音SEの有無だけが差。パズルを期待したプレイヤーは手応えの無さに戸惑う。

4. **小包の中身（髪・リボン・白紙の手紙）が見落とされやすい。** 開封は任意（`開けない` で素通り）。広場で先にミオへ話しかけると以後 WALK に戻れず、強い不気味演出を一度も見ずに章を終えられる。

## 3. 感情導線（3分／10分／終盤）

### ◆ 開始3分 ─ 掴み
- **強い。** `ch01_hook`：白い広場→「あなたは、誰ですか？」→空白の17:17通知（既読だけ付く）→画面白化→「── 3日前 ──」。謎・喪失・不気味を一気に提示。**3分以内の謎提示は明確に達成。**
- リスク: 直後の `ch01_morning_new`（台所・叔母、11ビート）が最も静かな箇所で、掴み直後にテンポが落ちる（§4）。「母のエプロン」「母の部屋のドアが少し開いている」の不穏は良いが長め。

### ◆ 10分 ─ ミオへの興味
- 設計上の核は `ch01_clocktower`：「座り心地じゃない／ここだと（剥がす音が）少し止まる」「ミオ」と呼ぶと「今のは、ちゃんと私だった」。**キャラ・メカニクス・テーマを同時に立てる最重要シーン。**
- **問題:** このシーンは §2-1 の順序破壊でスキップ可能。通れば10分以内に興味は十分立つが、外れると「不思議ちゃん」程度の印象で終わるリスク。**＝条件付き達成。** クロックタワー導入を必ず通す配線が必要。

### ◆ 終盤 ─ 続きを遊びたいか
- `ch01_080_truth`（「椅子が消えたんじゃない／関係が白く抜けてる」）でテーマが言語化され腑に落ちる。
- `ch01_anlog_flood`（観測ログ＋??の空白メッセージ「来て／待ってた／名前呼んで／見ないで／でも忘れないで」→記録化失敗：本人発話）は本章屈指の演出。
- `ch01_anlog_end` の送信者名 ミオ→トウ 反転は良い余韻。**ただし**最強の感情フック `legacy_ch01_090_phone`「ねえ、わたしの〇〇こと、〇〇ないでね（＝忘れないでね）」が**未発火**（§7）。これを終端に戻すだけで「続きを遊びたい」は大きく伸びる。

## 4. テンポ

- **谷:** 開幕の強い hook 直後 `ch01_morning_new`（11ビート）。情報密度の割に長く、minute 2〜3 で失速。叔母の会話を 2〜3 ビート圧縮、または「母の部屋のドア」の不穏を前に出すと締まる。
- **山:** `ch01_anlog_flood`（短い空白メッセージの連打＋システムログ）は緩急が効いて優秀。`ch01_hook` も◎。
- **ハブの停滞リスク:** `ch01_explore_bench` は3ホットスポット読了後の出口（17:17ボタン）が目立たず、テンポより先に「迷い」が生じる（§2-2）。
- **選択の手応え不足:** `ch01_060_choice`／`ch01_070_reconstruction` とも結果がほぼ収束。テンポは速いが「選んだ意味」が薄く、印象が平坦化。

## 5. 違和感演出（椅子・白層化・VNオーバーレイ）

| 演出 | 仕込み | 評価 |
|---|---|---|
| **椅子（5席目）** | WALK「5席目の跡」(eerie) / `ch01_explore_seat`（案内板4席・影は5つ）/ `ch01_bench_seats`（`[席1][席2][席3][席4][跡]`・古写真も4席）| ◯ 多重に反復され効果的。ただし最も生々しい `legacy_ch01_030_missing_chair`（「誰も覚えてない」「そんな椅子ありましたっけ」）が**孤立・未発火** |
| **白層化** | hook「画面が白くなった」/ `070a`「視界が白く弾ける」/ 名前が白く抜ける `＿　オ` 表示 / `080`「白く抜けてる」| ◎ 特に話者名 `＿　オ` の欠落表示は秀逸。テーマと直結 |
| **VNオーバーレイ** | 空白メッセージ（blank パルス）/ 送信者名の自動書き換え / `anlog_flood` の `??` ＋ `{b:…}` 抜け表示 | ◎ 仕組み・演出とも強い |

**結論: 種は十分。だが「椅子」の決定打（030）と感情の決定打（090）が共に孤立シーンに眠っている。** 既存の演出を新規追加せず、配線で表に出すのが最も費用対効果が高い。

## 6. プレイヤーが誤解する点

1. **「3日前」フラッシュバック構造** — hook が現在か過去か曖昧。台所が現在なのか過去なのか迷う。
2. **17:17の送信者** — ミオは「送っていない」と言うが既読が付く。意図的な不気味だが「バグ？」と取られうる。`anlog_end` の名前反転まで来て初めて腑に落ちる設計のため、それまでの保留が長い。
3. **WALK→夕方ジャンプ**（§2-1）— 時間/場所が無説明で飛ぶため演出ではなく不具合に見える。
4. **再構成パズル**（§2-3）— 「正しい断片を選ぶ」UIなのに全選択が同じ結末。正解選択の手応えを期待して空振る。
5. **操作説明不足** — WALK 画面は ←/→ ＋「Ⓐ 話す/調べる」ボタンが常時表示だが、初回に「歩いて近づく」誘導テキストが無い。`✦/…` の頭上アイコンと近接ハイライトはあるが、初見では役割が伝わりにくい。EXPLORE は「タップして調べる」ヒストあり（良）だが、退出導線の説明は無い。

## 7. Dead End / 進行不能

**ハードな進行不能（クリア不可）は無し。** ただし以下の「ソフトな袋小路／未発火」が体験を損なう。

| # | 種別 | 内容 | 影響 |
|---|---|---|---|
| D1 | 順序依存のコンテンツロック | WALK でオブジェ先行調査→夕方ハブ直行で、ミオ広場会話・小包・package分岐へ二度と戻れない | 中盤の感情・不気味演出を丸ごと失う |
| D2 | 未発火（孤立シーン）| `legacy_ch01_030_missing_chair`（椅子消失・「誰も覚えてない」）がどこからも参照されず再生されない | 椅子テーマの決定打が死蔵 |
| D3 | 未発火（孤立シーン）| `legacy_ch01_090_phone`「わたしの〇〇こと、〇〇ないでね」が章末フローから外れ未再生 | 最大の感情フックが死蔵 |
| D4 | 死にフラグ | `mio_first_talked` / `package_inspected` / `mio_reacted_observe|avoid|ask|wait` をセットするが誰も読まない | 機能上無害だが意図不明・保守性低下 |
| D5 | 選択の無効化 | `ch01_070_reconstruction` の `next:null` 選択も `ns()` で truth へ進む | パズルが実質ダミー |

## 8. 改善案 TOP10（優先度付き）

優先度: 🔴 高（体験の根幹）／🟡 中／🟢 低。**いずれも既存のフラグ機構（`sceneIfFlag` / `setFlag` / `next` / `ifAllFlags`）の再配線で実現でき、エンジン改修は不要。**

| # | 優先 | 改善案 | 具体策（最小変更） | 期待効果 |
|---|---|---|---|---|
| 1 | 🔴 | **クロックタワー導入を必ず通す** | WALK の `5席目の跡`/`時計塔` の `next` を夕方ハブ `ch01_explore_bench` ではなく、**昼の小規模VN**に変更し、戻り先を WALK に。夕方移行は「ミオに話しかける」起点に一本化 | §2-1/§3-10分/D1 を一掃。核シーンの取りこぼし防止 |
| 2 | 🔴 | **「忘れないでね」を章末に復帰** | `ch01_anlog_end.next` を `ch01_099_continued` → `legacy_ch01_090_phone` → continued の順に挿入（または anlog_end の後段へ） | 終盤の引きを最大化。D3 解消 |
| 3 | 🔴 | **ハブの退出導線を明示** | `ch01_explore_bench` の「17:17 →」を目立つ配色・文言（例「夕暮れが濃くなる… ▶ 17:17へ」）に。一定数調べたら自動で誘導表示 | §2-2/§4 の停滞解消 |
| 4 | 🟡 | **小包の見落とし防止** | ミオへ話しかける `sceneIfFlag` に「未開封なら一言促す」分岐、または WALK 初回に小包へ視線誘導の一言 | §2-4。不気味演出の取得率向上 |
| 5 | 🟡 | **再構成パズルに手応え** | `next:null`（空白メッセージ）選択時は「まだ足りない」一言を出して同シーンへ戻す。正解断片のみ truth へ | §2-3/D5。選択の意味を回復 |
| 6 | 🟡 | **椅子の決定打を本筋へ** | `legacy_ch01_030_missing_chair`（または要素）を `ch01_bench_seats` 前後に組み込み「誰も覚えてない」を体験させる | §5/D2。椅子テーマ強化 |
| 7 | 🟡 | **morning_new の圧縮** | 叔母会話を 2〜3 ビート短縮、「母の部屋のドア」の不穏を前倒し | §4 の谷を解消。掴みの勢い維持 |
| 8 | 🟢 | **WALK 初回チュートリアル** | 初進入時に「← → で歩く / Ⓐ で調べる」を数秒オーバーレイ表示 | §6-5 操作説明不足の解消 |
| 9 | 🟢 | **死にフラグの整理** | 参照されない `mio_first_talked` 等を削除、または将来の分岐に活用 | D4。保守性・意図の明確化 |
| 10 | 🟢 | **17:17 の保留を緩和** | hook 後など早い段階で「送信者の違和感」に一度触れさせ、終盤の反転を伏線化 | §6-2。誤解（バグ感）の低減 |
