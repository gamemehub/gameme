> 用途: 画像生成（GPT側）・手描き作画・ゲーム内実装受け入れのための一次資料。
> このドキュメントは **docs のみ**。ゲーム本体コード（`docs/rewrite-dev/index.html` 等）は変更しません。
>

現状ミオのビジュアルは2系統で実装されています。新しい画像はこの設計を上書き／差し替えできる前提で作成します。

| 用途 | 実装場所（参考・変更しない） | 形式 / サイズ | 表示CSS |

| 会話シーン立ち絵 | `index.html` の `MIO_SRC_NORMAL` / `MIO_SRC_ANXIOUS` 変数（インラインSVG, `viewBox 0 0 160 280`） | SVG data URI / 160×280（縦長 4:7） | `.mio-sprite` → `width:72px; height:auto;` 右下に表示 |

## 1. 顔の特徴

- 輪郭: 丸みのある卵型。顎は細く尖りすぎない。子ども〜思春期前半の柔らかさ。
- 全体は淡く血色のある肌（上記パレット）。鼻は点〜ごく短い線で控えめ（`#d4a888` 系）。
- 頬にうっすらチーク。感情が強いほど赤みが増す（白層化が進むと逆に色が抜ける／後述）。
- 表情の重心は **眉と瞳**。口は小さく、感情は眉と目で語らせる。
- 全体の印象キーワード: 「不安げ・控えめ・でも芯がある」。過度な笑顔より、ためらいや遠慮が基調。

## 2. 髪型

- ダークブラウンのセミロング。中央分けで前髪は柔らかく、左右に流れる房（バング）が頬にかかる。
- 頭頂はふんわり丸く、後ろ・ボリュームのあるシルエット（横顔で後頭部が見える）。
- 横髪（サイド）は耳〜肩のあたりまで内側にカーブして落ちる。
- 毛先は軽く、束感を出す（数本のハイライト線 `#7ab0cc` 相当の艶）。
- ヘアピン（水色）を **向かって右の側頭部** に1つ。固定アクセント（後述「小物」）。

## 3. 瞳

- 形: 大きめの楕円。下まつ毛は控えめ、上まつ毛で柔らかい印象。
- 虹彩: ブルーグレー（`#7890b0`）。下半分をやや明るく、上に瞳孔（`#202838`）。
- ハイライト: 上方に大きめの白点1つ＋下に小さな白点1つ（生気の表現）。
- 不安時: 虹彩がわずかに暗く（`#6880a8`）、瞳孔が大きくなり、目がやや伏せ気味・潤む。
- 眉: 通常はゆるい上向きアーチ。不安時は **内側が下がる「ハ」の字**。

## 4. 衣装構造

レイヤー構造（手前→奥）:

1. **上着**: 水色のカーディガン／薄手コート（`#b8d8f0`→`#88b8d8`）。前開き、肩から自然に落ちる。
2. **インナー**: オフホワイトのシャツ／ワンピース（`#f4f4f4`→`#dcdce8`）。襟元は詰まりすぎない。
3. **下**: 同系オフホワイトのスカート（膝上〜膝丈）。
4. 足元は本書では未指定（全身作画時に追補）。スニーカー想定。

ポイント:
- シルエットは「水色の外側 × 白の内側」の2層。**白層化差分はこの色構造を利用する**（後述）。
- 装飾は最小限。生活感のある普段着で、特別衣装ではない。

## 5. 白層化差分（重要・物語ギミック）

「白層化」= ミオが徐々に **色と存在感を失い、白く透けていく** 状態の段階表現。既存の「不安」スプライトでは髪まわり（ショール部）が `#ececec` の無彩色に置き換わっており、これが白層化の起点です。

**段階定義（4段階）** — 画像は段階ごとに別ファイルで用意:

| 段階 | キー | 内容 |
|------|------|------|
| 0 | `white00` | 通常。フルカラー。 |
| 1 | `white33` | 髪・上着の彩度を約30%低下。輪郭は保つ。チークが抜け始める。 |
| 2 | `white66` | 彩度を約60%低下＋全体に白被り。毛先・裾から白くフェード。瞳の色は最後まで残す。 |
| 3 | `white100` | ほぼ白（線画＋淡いグレー）。輪郭線のみ薄く残し、瞳に最後の色（ブルーグレー）を一点だけ残す。 |

作画ルール:
- 白層化は **「上から白いベールが重なる」** イメージ。完全な透明化ではなく、白の層が増える。
- **瞳の色を最後の砦** として残す（感情の最後の灯）。
- 同一表情・同一構図で段階差分を作る（差し替え時にズレないよう、レイヤー/構図を固定）。

## 6. 表情10種

会話シーンで使用。すべて **同一の顔の位置・サイズ・向き（正面）** で、目・眉・口・頬のみ差し替え可能にする。

| # | キー | 表情 | 眉 | 目 | 口 | 補足 |
|---|------|------|----|----|----|------|
| 1 | `normal` | 平常 | ゆるいアーチ | 普通に開く | 小さく閉じ | 既存 `MIO_SRC_NORMAL` 相当 |
| 2 | `smile` | 微笑み | 柔らかく上がる | 細める | 小さく上向き | |
| 3 | `anxious` | 不安 | ハの字 | 伏せ気味 | きゅっと結ぶ | 既存 `MIO_SRC_ANXIOUS` 相当 |
| 4 | `sad` | 悲しい | ハの字（強） | 潤む | 引き結ぶ／への字 | |
| 5 | `cry` | 泣き | ハの字（強） | 涙・赤み | 開いて震える | 涙の描写あり |
| 6 | `surprise` | 驚き | 上がる | 大きく見開く | 小さく開く | |
| 7 | `fear` | 怯え | ハの字＋寄る | 見開き・潤む | 開き気味 | 白層化と相性 |
| 8 | `shy` | 照れ | わずか下がる | 軽く伏せる | 小さく開く | チーク強め |
| 9 | `serious` | 真剣 | わずかに寄せる | しっかり開く | 引き結ぶ | 芯のある表情 |
| 10 | `empty` | 虚ろ（白層化進行時） | ほぼ水平 | ハイライト弱・色薄 | ゆるく開く | 段階2〜3と組み合わせ |

> 実装受け入れ: 既存は2値（normal/anxious）。10種は「キー→画像URL」のマップとして将来導入できるよう、命名で識別可能にする（§命名規則）。

## 7. 小物

| 小物 | 説明 | 配置 |
|------|------|------|
| ヘアピン（水色） | 既存SVGにある固定アクセサリ。`#60b8e0`/`#80cce8`/`#a0d8f0` の小さな飾り。 | 向かって右の側頭部・前髪の生え際付近 |
| （任意）小さな鞄 / ポシェット | 全身作画時の追補候補。普段着に合う簡素なもの。 | 肩がけ |

ヘアピンは **アイデンティティ要素**。全構図（正面・横顔・後ろ姿）で位置の一貫性を保つこと。後ろ姿でも右側頭部に見える。

## 8. 全身 / 横顔 / 後ろ姿の作画メモ

- **全身（正面）**: 縦長 4:7 を基準（既存立ち絵 160×280, 歩行 251×360 に準拠）。重心は中央。腕は体側に自然に。子どもらしいやや内股気味の立ち姿。地面影は実装側で付与するため、画像は基本 **影なし・透過背景**。
- **横顔（プロフィール）**: 後頭部のボリュームと前髪の流れを見せる。鼻先は控えめ、睫毛のシルエットを明瞭に。ヘアピンが見える側（右向き）を基本とする。
- **後ろ姿**: 後頭部の毛流れ・つむじ、上着の背中のドレープ、スカートの裾。右側頭部のヘアピンがちらりと見える。寂しさ・去っていく印象を出せる構図。白層化との相性が良い。

各構図は **同一キャラ比率・同一カラーパレット** を厳守。複数アングルで顔の年齢感がブレないこと。

## 9. 画像生成用プロンプト（GPT向け）

> 著作権・既存IPに依存しない、オリジナルキャラとして生成。日本語/英語どちらでも可。背景は透過 or 単色（後で切り抜ける）。

**共通スタイル指定（プレフィックス）:**
```

blue-grey eyes, delicate expression, full transparent background (PNG with alpha), no ground shadow,
consistent character design, front-facing, head-to-toe in frame
```

**正面・通常（`mio_full_normal`）:**
```

```

**不安（`mio_face_anxious`）:**
```

```

**白層化・段階2（`mio_full_white66`）:**

**横顔（`mio_profile_normal`）:**
```

```

**後ろ姿（`mio_back_normal`）:**
```

```

> 表情10種・白層化4段階は、上記をベースに「表情・段階の指定文」だけを差し替えて量産する。**構図・比率・カラーは固定のまま** にすること（差し替え整合のため）。

## 10. 最終手描き差し替え時の注意点

- **構図・比率・キャンバスサイズを全カットで固定**。手描き版もGPT版と同じ枠・同じ重心で描く（実装側で位置を再調整しなくて済むように）。
- 透過PNG・背景なし・影なしを厳守（影は実装の `drop-shadow` が付与）。
- カラーパレット（§0）から逸脱しない。逸脱する場合は本書を先に更新してから差し替える。
- ヘアピンの位置・瞳の色は **全カット共通のアイデンティティ**。ブレさせない。
- 白層化は「線画＋白ベール」で段階管理。瞳の色を最後まで残す。
- ファイル名・配置パス・サイズは §11〜13 の規則を厳守（実装が名前で参照するため）。
- 差し替えはまず採用候補を `assets/_incoming/`（任意の一時置き場）に置き、人間が採用判断 → 正式名で `assets/characters/mio/` に確定、の順を推奨。

## 12. assets 配置パス

既存アセットは `docs/rewrite-dev/assets/` 直下にあります。キャラ画像が増えるため、ミオ専用のサブフォルダを新設します（**画像追加は別PR**）。

```
docs/rewrite-dev/assets/characters/mio/
  ├─ face/    … 表情差分（バストアップ）
  ├─ full/    … 全身・白層化差分
  └─ pose/    … 横顔・後ろ姿
```

- ステージ/本番（`docs/rewrite-stage/`, `docs/rewrite/`）へは、dev で確定後に同一相対パスで反映。
- 既存の `assets/mio_sprite_front.png` は当面そのまま残し、`full/mio_full_normal.png` を後継として用意（後方互換でフォールバック）。

## 13. 画像サイズ・形式・命名規則

**形式:**
- PNG / RGBA（アルファ透過）。背景・接地影なし。
- sRGB。

**サイズ（基準。@2x 推奨で書き出し、実装はCSSで縮小表示）:**

| 種別 | 推奨実寸 | 比率 | 表示参考 |
|------|----------|------|----------|
| 表情（face, バストアップ） | 360×360（@2x: 720×720） | 1:1 | 会話立ち絵 `.mio-sprite width:72px` |
| 全身（full） | 320×560（@2x: 640×1120） | 4:7 | 既存 160×280 / 251×360 に準拠 |
| 横顔・後ろ姿（pose） | 320×560 | 4:7 | 同上 |

**命名規則:**
```
mio_<view>_<expression>[_<white>].png
```
- `<view>`: `face` | `full` | `profile` | `back`
- `<expression>`: §6 の10キー（`normal` `smile` `anxious` `sad` `cry` `surprise` `fear` `shy` `serious` `empty`）
- `<white>`（任意）: `white00` | `white33` | `white66` | `white100`（省略時 = white00）

例: `mio_face_anxious.png` / `mio_full_normal_white66.png` / `mio_back_normal.png`

## 14. 既存コードへの組み込み方針（将来PR用メモ）

> 変更しない。来たる実装PRの設計メモとして記録。

1. **会話立ち絵**: 現状の `MIO_SRC_NORMAL` / `MIO_SRC_ANXIOUS`（インラインSVG）を、表情キー→画像パスのマップに拡張。
   ```js
   // 例（将来）
   var MIO_FACE = {
     normal:  'assets/characters/mio/face/mio_face_normal.png',
     anxious: 'assets/characters/mio/face/mio_face_anxious.png',
     // … smile/sad/cry/surprise/fear/shy/serious/empty
   };
   ```
   `updateMioSprite()` のキーワード判定（既存）を活かしつつ、シーンデータ側から表情キーを明示指定できる経路を追加。
2. **白層化**: 既存のフラグ機構（`CH01_STATE.flags` 等）から白層化段階を引き、`_white33/66/100` のサフィックスでファイルを選択。
3. **歩行NPC**: `assets/mio_sprite_front.png` を `full/mio_full_normal.png` に差し替え or 併存。
4. 変更は最小限・後方互換（画像が無ければ現行SVG/PNGにフォールバック）。

## 15. フォールバック表示方針

画像が未配置・読み込み失敗でもゲームが破綻しないこと:

1. 指定表情キーの画像が無ければ → `normal` 画像にフォールバック。
2. `normal` 画像も無ければ → 既存のインラインSVG（`MIO_SRC_NORMAL` / `MIO_SRC_ANXIOUS`）を使用。
3. 白層化サフィックス画像が無ければ → 同表情の `white00` にフォールバック。
4. `<img onerror>` で上記の段階的フォールバックを行い、最悪でも常に何かが表示される状態を保つ。
